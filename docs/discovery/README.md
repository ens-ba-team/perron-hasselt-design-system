## Two things to know before using these

1. **Older notes cite rules as `R0`–`R26`.** That numbering belongs to `product-knowledge.md`, which lives
   in the designer's Obsidian vault and is **deliberately not in this repo** (decided 2026-10-13: it is
   training material, not an input). The BRD numbers the same rules `BR01`–`BR29` and the two do not line
   up one-to-one — see [`../product/rule-number-map.md`](../product/rule-number-map.md). Always cite `BR`.
2. **This material was written while the Obsidian vault was the source of truth** (until 2026-10-13), so it
   can lag the product docs. Each file's header says what it is and what it is not.
